## Wave interaction

The spring force and damping approach is adapted from JIEJOE-WEB-Tutorial/016-wavy-lines:
https://github.com/JIEJOE-WEB-Tutorial/016-wavy-lines

The repository credits the original wave effect to Antoine Wodniack. This implementation changes SVG paths to Canvas and adds seeded ambient noise, fixed-step timing, resizing, offscreen handling, accessibility and deterministic replay.
